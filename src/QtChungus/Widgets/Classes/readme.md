All `.cs` files in this folder are originally auto-generated by `QtChungus.Generator`.

All changes to these files may be overwritten, except:
- `#region Inheritance` will persist and be re-inserted between the record signature and the record's opening bracket,
- `#region Members` will persist and be re-inserted between the last auto-generated member and the record's closing bracket.

Also:
- If the source generator detects any other region names, nested regions of any kind, or unexpected `#endregion` directives, it will report failure and exit without making any changes.
- If there are multiple regions with the same name that's one of known region names, their content will be concatenated under a single region.
- If there are any files left untouched by the generator (e.g. manually created, or no longer source-generated), the generator will prompt you to delete them manually.
